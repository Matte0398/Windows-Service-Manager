# Windows Manage Services

PowerShell utility for managing Windows services.

The script allows you to perform service management operations such as checking, stopping and restarting services.  
To avoid permission-related errors, run the script as Administrator.

## Features

- Check service status
- Stop services
- Restart services
- Useful for Windows operations and troubleshooting

## Use Cases

- Windows service troubleshooting
- Operational support
- Monitoring remediation tasks

## Usage

```powershell
powershell.exe .\manage_service.ps1
```
